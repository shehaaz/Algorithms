About this project

This repository started as a small collection of Java implementations of algorithms (see src/). The site you are looking at is a companion that visualizes the same ideas in the browser so they are easier to learn and review.

Everything runs client-side — no framework, no build step. The full source lives in index.html, css/styles.css, and the js/ folder.

Static visualizer · deployed via GitHub Pages.
